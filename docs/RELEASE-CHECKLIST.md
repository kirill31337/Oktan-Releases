# Публикация и проверки

Готовые выпуски находятся в [GitHub Releases](https://github.com/kirill31337/Oktan-Releases/releases). Исходный код остаётся закрытым. Этот репозиторий содержит публичные документы, иллюстрации и готовые файлы приложения.

Перед публикацией проверяются поведение приложения, подписанный APK, номер версии и неизменность сертификата подписи. Релиз сначала создаётся как черновик; APK, `update.json` и `SHA256SUMS` загружаются до открытия выпуска. После публикации проверяется скачивание без авторизации и совпадение контрольной суммы.

Проверки приложения с контролируемыми ответами не подтверждают доступность сайтов сетей АЗС во всех сетях и не гарантируют наличие топлива при приезде. Получение открытого ответа не заменяет разрешений правообладателей; сведения о них и ограничениях приведены в [описании источников](SOURCES.md).
